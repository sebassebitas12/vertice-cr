# Negocio

Aquí vive la documentación de negocio **vigente** de Vértice CR.

## Estado

Por ahora el material está en `heredado/`, copiado de la entrega académica `Tienda-de-Impresion3D`:

- `01-PRODUCTO-Y-ALCANCE.md`: producto, roles, capacidad de fabricación.
- `02-NEGOCIO-Y-ESTADOS.md`: entidades, pedidos, cotización, checkout.
- `03-UX-Y-FLUJOS.md`: rutas y experiencia.
- `LibroDeMarca_Vertice_CR.pdf`: identidad de marca.

## Cuidado

Ese material está escrito para React + Vite + JSON Server y para los requisitos de una entrega académica (por ejemplo, "dos flujos N8N", "Recharts"). **No todo aplica al startup.** Al migrar una regla a un documento vigente, se revisa y se quita lo que era requisito del curso.
