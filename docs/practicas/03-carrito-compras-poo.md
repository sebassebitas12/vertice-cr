# Práctica #3 — Carrito de compras con POO

- **Estado:** realizada, según informó el estudiante.
- **Lenguaje:** JavaScript
- **Carácter:** ejercicio académico; no es el carrito de producción.

## Enunciado resumido

Crear `Producto.js` (nombre, precio, `cantidadDisponible`), `CarritoDeCompras.js` (colección privada, `agregarProducto()`, `calcularTotal()`, `aplicarCupon()`, `mostrarResumen()`) y `main.js`. Crear al menos cuatro productos, probar compra y stock insuficiente, y mostrar el resumen. Al agregar, el stock disminuye sin volverse negativo. Archivos separados con `module.exports`.

## Conceptos asociados

Objetos que encapsulan estado, métodos, listas privadas, validaciones, reglas de negocio y cálculo de totales.

## Registro y alcance

La práctica permite usar IA para estudiar o revisar, siempre que el estudiante comprenda el código. Se registra como **realizada según lo informado**, sin reproducir soluciones ni asegurar resultados concretos.

**No trasladar literalmente a Vértice:** su catálogo se fabrica bajo pedido; el ejercicio presupone existencias disponibles y descontables. Un sistema real necesitará reglas propias y datos operativos aprobados cuando corresponda.

**Archivos de soluciones:** permanecen fuera del repositorio.
