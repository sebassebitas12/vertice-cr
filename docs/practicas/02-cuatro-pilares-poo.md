# Práctica #2 — Aplicando los cuatro pilares de POO

- **Estado:** realizada, según informó el estudiante.
- **Lenguaje:** JavaScript
- **Carácter:** ejercicio académico; no es módulo de la tienda.

## Enunciado resumido

Modelar un zoológico con archivos separados `Animal.js`, `Perro.js`, `Gato.js`, `Zoologico.js` y `main.js`. La clase base define `#nombre`, `#energia`, `moverse()` y getters. `Perro` y `Gato` heredan y responden distinto a `hacerSonido()`. `Zoologico` administra un arreglo privado, agrega animales, hace ruido y alimenta sin acceder directamente a campos privados. Se pide `module.exports` y demostración por consola.

## Conceptos asociados

Encapsulamiento, herencia, polimorfismo, abstracción, estado privado y métodos públicos.

## Registro y alcance

El material original indica realizar la práctica individualmente y sin IA. Aquí se registra el **contenido de una práctica ya realizada**; no se genera solución, ni se afirma haber visto su código o capturas.

**Aplicación a Vértice:** ninguna implementación inmediata. Los conceptos podrán servir para comprender modelado de dominio en futuras clases de backend.

**Archivos de soluciones:** permanecen fuera de este repositorio.
