# 06 — MySQL: del DER a una biblioteca

- **Fechas:** 26 y 27 de octubre de 2026.
- **Fuente:** BD_Practica2_DER_Creacion_BD.pdf, “Práctica #2 — Del DER a la base de datos: sistema de biblioteca”.
- **Estado:** estudiada y practicada según declaración del estudiante; capturas compartidas muestran las tablas y cinco préstamos consultados. Sin calificación registrada.
- **Herramientas:** MySQL Server, MySQL Workbench y draw.io.
- **Objetivo:** pasar de un modelo entidad-relación a tablas con PK/FK y datos relacionados.
- **Conceptos:** entidades y atributos, relaciones 1:N, claves, integridad referencial, tipos, NOT NULL, UNIQUE, AUTO_INCREMENT, NULL e instrucciones básicas de SQL.
- **Requisitos del ejercicio:** cuatro entidades; al menos cuatro autores, seis libros, tres clientes y cinco préstamos; consultar ID existentes antes de referenciarlos.
- **Entregables solicitados:** DER, practica2.sql con bloques comentados por ejercicio y captura de SELECT sobre préstamos.
- **Evidencia revisada en conversación:** DER con tres relaciones 1:N; consultas de autores y clientes; seis libros confirmados; resultado final con cinco préstamos.
- **Pendiente documental:** revisión completa del archivo SQL final, comentarios y coherencia entre definiciones y correcciones. No se afirma entrega formal.
- **Restricción del enunciado:** trabajo individual sin IA; aquí se registra el aprendizaje sin incorporar su solución SQL.
- **Alcance:** ejercicio independiente; no añade una biblioteca ni cambia el motor de Vértice.
