# Publicación inicial del repositorio

## Qué hice

Publiqué la base documental de Vértice CR en el repositorio `sebassebitas12/vertice-cr`.

## Qué aprendí

Un repositorio GitHub vacío puede tener un commit inicial mínimo. Antes de publicar archivos conviene revisar la rama predeterminada y conservar ese commit como padre para mantener un historial conectado.
