## Evidencia a guardar en la prueba

- Una captura propia por ruta y viewport de aceptación (390, 768, 1440 px), con ubicación de archivo.
- Componente/código concreto cuando se reutilice una fuente open source y ruta del aviso de licencia.
- Nota breve con rasgo conservado, decisión y estado visual: propuesta / elegida / rechazada.
- Screenshots de N3D/Tailwind Admin pueden ser evidencia privada de referencia; el producto no debe incorporar sus fotos, marca o páginas como contenido propio.
